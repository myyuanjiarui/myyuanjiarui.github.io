Rust的出现更像是为了解决C/C++遗留了几十年的老问题，目前主要应用于系统编程/内核、云基础设施、WebAssembly、命令行工具、嵌入式开发。

- 解决内存泄漏

  C/C++写多线程代码极易出现内存安全问题，例如悬空指针、数据竞争之类的，C/C++通常采用智能指针，Java/Python通常采用运行期的垃圾回收器（GC）来解决。但Rust通过一套设计哲学，在编译期间就把所有的内存Bug挡住。

  ```text
  任何一份数据，在任意时刻只能有多个读或者一个写两种情况。
  ```

  - 所有权转移

    Rust中，直接赋值相当于所有权转移，原数据变量会被销毁。

    ```rust
    let s1 = String::from("Hello");
    let s2 = s1;
    println!("{}", s1); // 报错，读都不可读
    ```

  - 借用

    借用就是不转移所有权，也不复制，发一个引用出去：`&`可读引用，`&mut`可写引用

    ```rust
    let mut s = String::from("hello");
    let r1 = &s;
    let r2 = &s;
    println!("{} and {}", r1, r2); // r1和r2之后就不用了
    let r3 = &mut s;
    println!("{}", r3); // 不报错
    println!("{}, {} and {}", r1, r2, r3); // 报错，因为违背了同一时刻对同一份数据要么有多个读或者只能有一个写
    ```

  练习：单词频率统计

  ```rust
  use std::collections::HashMap;
  
  fn count_words(text: &str) -> HashMap<String, usize> {
          let words = text.split_whitespace();
          let mut m: HashMap<String, usize> = HashMap::new();
          for word in words {
                  *m.entry(word.to_string()).or_default() += 1; // 核心
          }
          return m;
  }
  
  fn main() {
          let text = String::from("the quick fox jumps over the lazy dog the fox runs");
          let counts = count_words(&text);
          println!("{:?}", counts);
          println!("原始字符串：{}", text);
  }
  ```

  

- 解决空指针

  C/C++中经常会出现有时候函数返回空值的情况，这在调用时几乎看不出可能返回空，从而容易出现空指针的Bug，Rust的`Option<T>`类型可以用来表达"可能有值，也可能没有"，有两种形态：`Some(T)（`这里有个值）和`None（`什么都没有），例如：

  ```rust
  fn find_word(text: &str, target: &str) -> Option<usize> {
    text.split_whitespace().position(|w| w == target) // 不加 `;` 代表作为函数返回值，相当于return ...;
  }
  ```

  上述函数返回的不是数字，而是Option类型，需要用match关键字解开：

  ```rust
  match find_word(&text, "fox") {
    Some(idx) => println!("找到位置了{}", idx),
    None => println!("没找到"),
  }
  ```
