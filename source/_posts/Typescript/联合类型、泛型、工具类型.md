TypeScript更像是JavaScript的超类——TS代码最终都会被编译成JS运行。所以TS的核心价值在编写代码阶段。

## 联合类型

联合类型要解决的问题一个变量可能既是类型A又是类型B，如果是Java会采样几个类的继承来解决，但是TS直接支持`|`来添加不同类型，从而在类型系统层面可以直接表达"这个值既是A又是B"。

```ts
type Result = "success" | "error" | "pending"
type ID = number | string; // 一个变量可以是多种类型之一
```

```ts
// 一个函数，接受number或string都合法
function printId(id: number | string) {
  console.log(id)
}
printId(101);
printId("abc");
printId(true);
```

一个实际的例子，网络请求结果处理器：

```ts
type ApiResult = 
		| {status: "loading"}
		| {status: "success"; data: string}
		| {status: "error"; message: string};
```

这个例子体现了**可辨识联合**，每个分支都有一个相同的字段（`status`）作为标签，TS靠这个字段来收窄类型。

```ts
// interface: 描述"对象的形状"
interface User {
  id: number;
  name: string;
}

// type: 描述"任意类型的别名"
type User = {id: number; name: string}; // 这个interface能做
type ID = number | string; // interface做不到这个
```



## 泛型

把类型当参数传入。

```ts
type ApiResult<T> = 
		| {status: "loading"}
		| {status: "success"; data: T}
		| {status: "error"; message: string};
```



## 工具类型

TypeScript的工具类型让用户可以直接对类型操作，不像Java为了类型安全需要写一堆继承体系，举个例子：

```ts
interface User {
  id: number;
  name: string;
  email: string;
  age: number;
}
```

- `Partial<T>`——把所有字段变可选

```ts
type UserUpdate = Partial<User>;
// 等价于
// {id?: number; name?: string; email?: string; age?: number}
```

- `Pick<T, K>`——只取需要的字段

```ts
type UserCard = Pick<User, "name" | "email">
// 等价于：{ name: string; email: string }
```

- `Omit<T, K>`——排除不需要的字段

```ts
type UserCreate = Omit<User, "id">
// 等价于：{name: string; email: string; age: number}
```
