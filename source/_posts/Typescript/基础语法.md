## 1. 变量声明

```typescript
let count = 0;        // 可变，块级作用域（类似 Java 局部变量）
const name = "Yuan";  // 不可变绑定（类似 C++ const）
```

注意：`const` 是**绑定不可变**，不是值不可变——对象的字段仍可修改，除非配合 `Readonly<T>`。

```typescript
const user = { name: "Yuan" };
user.name = "Other"; // ✅ 合法，const 只约束 user 本身不能被重新赋值
```

## 2. 基础类型

```typescript
let a: number = 3.14;     // 没有 int / float 之分，统一 number
let b: string = "hello";
let c: boolean = true;
let d: null = null;
let e: undefined = undefined;

let f: any = "anything";      // 关闭类型检查，尽量避免使用
let g: unknown = "something"; // 比 any 安全，使用前必须先收窄类型
let h: never = ...;           // 不可能存在的值（用于穷举检查）
```

**`unknown` vs `any`**：`any` 直接放弃类型检查；`unknown` 表示"类型未知，但使用前必须先判断类型"。优先使用 `unknown`。

## 3. 数组和元组

```typescript
// 数组——两种写法等价
let nums: number[] = [1, 2, 3];
let strs: Array<string> = ["a", "b"];

// 元组——固定长度、固定类型（类似 Python tuple，Java/C++ 无原生对应）
let point: [number, number] = [10, 20];
let entry: [string, number] = ["age", 25];
```

## 4. 函数

```typescript
// 基础写法
function add(a: number, b: number): number {
    return a + b;
}

// 可选参数（加 ?，必须放在必填参数之后）
function greet(name: string, title?: string): string {
    return title ? `${title} ${name}` : name;
}

// 默认参数（与 Python 类似，建议放在参数列表最后）
function repeat(str: string, times: number = 3): string {
    return str.repeat(times);
}

// 箭头函数
const double = (n: number): number => n * 2;
```

返回值类型通常可省略，TS 能自动推断；但显式标注是良好习惯。

## 5. 对象和接口

```typescript
interface Point {
    x: number;
    y: number;
    label?: string;  // 可选字段
}

const p: Point = { x: 1, y: 2 }; // ✅ label 可以省略
```

- `type` vs `interface`
```typescript
// interface：描述"对象的形状"
interface User {
    id: number;
    name: string;
}

// type：描述"任意类型的别名"
type ID = number | string;          // interface 做不到这个
type User = { id: number; name: string }; // 这个 interface 也能做
```

## 6. 类

写法上与 Java 最接近，但有 TS 特有的简写语法：

```typescript
class User {
    // 构造函数参数加访问修饰符，可直接声明为字段
    constructor(
        public name: string,
        private age: number,
        readonly id: number   // 只读字段
    ) {}

    greet(): string {
        return `Hi, I'm ${this.name}`;
    }
}

const user = new User("Yuan", 25, 1);
```

访问修饰符 `public`（默认）/ `private` / `protected`，语义与 Java 一致。

## 7. 类型断言

当开发者比编译器更确定某个值的类型时使用：

```typescript
const input = document.getElementById("name") as HTMLInputElement;
input.value; // ✅ 不断言时 TS 只知道是 HTMLElement，没有 value 字段
```

等价于 Java 的强制类型转换 `(HTMLInputElement) element`，但**只在编译期生效，运行时不做检查**。

## 8. 可选链与空值合并

JS/TS 特有语法，C++/Java 无直接对应。

```typescript
// 可选链 ?.——链中任意一步为 null/undefined 时短路返回 undefined
const city = user?.address?.city;

// 空值合并 ??——仅当左侧为 null 或 undefined 时取右侧
const name = user.name ?? "匿名";
```

**`??` 与 `||` 的区别**：`||` 在左侧为任意 falsy 值（包括 `0`、`""`）时取右侧；`??` 只在 `null` / `undefined` 时取右侧。

## 速查表

| 概念 | TS 写法 | 对应概念 |
|---|---|---|
| 不可变变量 | `const` | C++ `const`，Java `final` |
| 联合类型 | `string \| number` | C++ `std::variant` |
| 可选字段 | `name?: string` | 无直接对应 |
| 可选链 | `obj?.field` | 无直接对应 |
| 类型断言 | `x as Type` | Java `(Type) x` |
| 泛型约束 | `<T extends X>` | Java `<T extends X>`（几乎一致） |
| 元组 | `[string, number]` | Python tuple |
